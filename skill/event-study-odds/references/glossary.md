# 術語表

每個詞一句話定義，加一句「容易搞錯的地方」。後者比前者有用。

---

| 術語 | 定義 | 容易搞錯的地方 |
|---|---|---|
| **cooldown／冷卻期** | 兩個同類事件之間至少間隔的**交易日**數；期間只保留第一個，用來去掉同一輪走勢的重複計數 | 它**不是交易冷卻**，不是「下單後幾天不能賣」。常用 10 日；波動極大（ATR>6%）可用 15 日。改了它，n 和結論都會變 |
| **事件（event）** | 某一天收盤滿足了事件定義，且通過冷卻期去重 | 事件不是「買點建議」，只是「歷史上出現過類似狀態」的標記 |
| **可用樣本（n）** | 事件中往後還有完整 H 根 K 可觀察的數量 | 事件數 ≠ 可用 n（例：29 vs 27）。尾端事件還沒走完窗口，不能算報酬 |
| **前復權** | 把歷史價格按拆股／派息調整，使報酬序列連續 | 前復權會改變**歷史絕對價位**。拿復權價去對「當時的新聞說 3.2 元」會對不上；對均線的影響是平滑的，不會改變報酬方向 |
| **MFE** | Maximum Favourable Excursion，持倉期間最大有利偏移 | 它是「曾經賺過多少」，不是「最後賺多少」；不能拿 MFE 當目標價 |
| **MAE** | Maximum Adverse Excursion，持倉期間最大不利偏移 | 「中位報酬 +1.64% 但 MAE 中位 −8.54%」的意思是：要先承受約 8.5% 的帳面回撤，才換到那個報酬 |
| **未結（率）** | 在 H 日內既沒觸及止損、也沒觸及目標的比例 | 未結率高不等於「安全」，它代表這組障礙在這段歷史上很少走完；期望值只由已結樣本計算，樣本會變少 |
| **超額（pp）** | 事件格的淨期望 − 同參數隨機基準的淨期望，單位是百分點 | **超額 ≤0 代表這個訊號不優於「什麼都不看」**。正的絕對報酬不代表有 Alpha，可能只是市場在漲 |
| **T+20／T+40** | 事件日之後第 20／40 個**交易日** | 不是日曆日，也不是「20 天後的那一天」。同一組障礙在 T+20 與 T+40 可以一正一負；引用必須寫明期限 |
| **prior_low** | 當日之前 250 根 K 的最低價，**不含當日** | 含當日的版本會讓 `close < prior_low` 永遠不成立，F/G 事件全部變 0，且不會報錯 |
| **九格／路徑矩陣** | 3 種止損 × 3 種目標的淨期望表（報告常用 −9/−12/−15% × +10/+15/+20%） | 預設 CLI 是 6×5，不是九格。不對齊 `--stops/--targets`，數字和報告對不上是正常的 |
| **隨機基準** | 在同樣的資料上，每隔固定交易日（預設 20）無條件進場，跑同一套路徑模擬 | 它是**同參數**的對照組，不是「買入持有」。用它比較時，止損／目標／成本必須完全一致 |
| **Alpha／Beta** | Alpha＝扣掉市場／板塊後的超額；Beta＝隨市場／板塊一起動的部分 | 個股漲不等於有 Alpha。把板塊 Beta 當成個股 Alpha，是最常見的歸因錯誤 |
| **倖存者偏差** | 只研究「活到現在」的標的，忽略已退市／被併購者，結論偏樂觀 | 用今天還在的 13 檔鈾礦股回測 2016 年，本身就已經排除了失敗者 |
| **時期偏差** | 合併樣本裡某些年份的表現特別好或特別壞，主導了整體結論 | 整體勝率 52% 可能藏著近三年只有 46%。所以必須分年拆，並看「近三年」紅線 |
| **真破位／假破位** | 真破位：收盤 < 前低（趨勢延續）；假破位：盤中破前低、收盤收回（反轉試探） | 兩者只差一個「收盤」，結論相反。把「跌破前低」當成單一事件，會得到互相矛盾的統計 |
| **級別 A/B/C/D** | 樣本量等級：≥100／30–99／10–29／<10 | 它不是「品質評分」，是**發言權限**。C 級只能說方向，D 級禁止用勝率下結論 |

---

## 一句話記住三個最常錯的

1. **事件數 ≠ 可用 n**：尾端事件還沒走完窗口。
2. **超額 ≤0 ＝ 沒有 Alpha**：絕對報酬會騙人，基準不會。
3. **T+20 ≠ T+40**：期限不同，答案可以相反。
