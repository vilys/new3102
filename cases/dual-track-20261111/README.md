## 這組案例教會我們什麼

1. **同一個形態，在不同狀態下結論相反。** 01164 的「反彈」與 09696 的「盤整」都不能套用「跌深即反彈」的直覺。
2. **相對強弱會逆轉。** 兩個月前最弱的，可能是現在的 Alpha 來源；判斷要看「同一個窗口內誰在動」。
3. **短線與中線可以給出相反的答案。** 01164 的 20 日為負、40 日為正——這不是矛盾，是期限結構。
4. **能買幾手，不等於該買。** 09696 的倉位算得出來，但它對應的是九組全負的期望。
