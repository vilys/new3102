# event-study-odds — 事件研究與賠率計算

把「跌得夠多了，能不能買」這種直覺問題，翻譯成可驗證的**機率、賠率與期望值**。

這不是一個「預測漲跌」的工具。它輸出的是：

> 在什麼價位、用多寬的止損、博多大的目標，歷史上的勝率與淨期望是多少，
> 以及**這個數字是否值得相信**。

## 能力範圍

### 擅長（已用真實數據驗證）

| 能力 | 具體產出 |
|---|---|
| 位置判斷的量化 | 「在 X 價位進場，20 日內達標／被掃的機率各是多少」 |
| 止損幾何 | 用 ATR 校準止損寬度，找出「再放寬已無邊際收益」的拐點 |
| 期望值比較 | 把「博反彈」拆成 16 組止損×目標的淨期望矩陣 |
| 真假破位分辨 | 收盤破位（趨勢延續）vs 盤中破收盤收回（反轉試探） |
| Alpha 歸因 | 區分個股 Alpha、板塊 Beta、大盤／利率的地心引力 |
| 形態效力檢驗 | 某形態在你關心的板塊上，到底有沒有超額報酬 |
| 倉位換算 | 由風險預算反推手數，含連續虧損情境 |
| 偏誤偵測 | 倖存者偏差、時期偏差、事件重複計數、樣本量不足 |

### 有條件能做（必須聲明限制）

- **支撐位**：給「階梯＋觸及概率」，不是一個精確價位。
- **時間預測**：給「20 日內曾觸及的機率分布」，不是「什麼時候會漲」。
- **目標價**：由 MFE 分布反推，不是由估值模型反推。

### 不做

基本面估值、重大事件跳空（財報／併購／政策）、新股（事件<10）、極低流動性標的、衍生品與槓桿 ETF、跨板塊移植形態結論。

### 已驗證邊界（誠實標註）

- **標的**：2 隻港股深度研究（01164、09696）
- **板塊合併**：鈾礦／核能 13 標的、鋰礦／鋰電 15 標的
- **市場**：港股（騰訊）、美股／ETF（Yahoo）
- **未測**：A 股、日股、歐洲、加密貨幣、期貨、可轉債

在未測市場上方法是可用的，但**成本、冷卻期、事件閾值都要重新校準**，且須在報告中說明是首次應用。

## 五條心法

1. **概率只能從逐日數列算，不能從搜索摘要算。**
2. **先問「這是不是比什麼都不看更好」。** 隨機進場基準是照妖鏡。
3. **一個標的的勝率是故事，一組合併樣本才是統計。**
4. **分年拆開，否則牛市樣本會替你撒謊。**
5. **Alpha 屬於板塊與週期，不屬於形態。**

第 5 條是用一次完整誤判換來的：同一個「假破位」形態，在鈾礦板塊 T+20 平均 +6.62%、勝率 60.2%；搬到鋰礦板塊只剩 +0.52%、勝率 49.6%，**比隨機進場的 +2.39% 還差**。

## 工作流

| 步驟 | 做什麼 |
|---|---|
| 0 | 先分類標的狀態：探底／破位下行／上升趨勢回調 |
| 1 | 抓逐日 OHLC（港股分段抓取，美股走 Yahoo） |
| 2 | 本地計算 MA/BOLL/RSI/KDJ/MACD/ATR |
| 3 | 定義事件並去重（10 日冷卻期） |
| 4 | 前向報酬分布（均值／中位／P25／P75／MFE／MAE） |
| 5 | 路徑模擬：止損與目標誰先觸及 |
| 6 | 與隨機進場基準對照 |
| 7 | 跨標的合併，對抗倖存者偏差 |
| 8 | 分年勝率、破位序列、成交分布三項檢查 |
| 9 | 倉位與成本換算 |
| 10 | 報告與交付前自檢 |

完整操作手冊見 [`skill/event-study-odds/SKILL.md`](skill/event-study-odds/SKILL.md)。

## 驗證記錄

腳本不是紙上設計，是用真實數據校準過的：

- 事件計數（可複現）：01164 截至 2026-11-10（2,920 根），事件 A `raw n=72 / forward n=71`；09696 截至 2026-11-10（1,068 根），A `n=27`、G `n=13`
- 路徑引擎恆等式：障礙放寬至 ±1000% 時，路徑均值 = 前向均值，差異 `0.000000`
- 同日雙觸：合成資料驗證，保守判為止損
- `prior_low` 不含當日：01164 在 2026-10-23 的 `prior_low=1.8950`，而該日 `low=1.865`（若含當日會等於 1.865）；1.865 要到 10-26 才進入 `prior_low`
- 指標：MA20 本地 2.6627 vs 第三方 2.660；MA60 2.5647 vs 2.564
- 打包校驗：`package_skill.py` 回報 `Skill is valid`

**已退役的錨點**：舊版 README 曾以「事件 A `n=67`」作為校準基準，但用現行腳本在三個截點（2026-09-11 / 10-30 / 11-10）都複現不出 67（分別為 raw 71 / 72 / 72）。
同一份數據在 2026-09-11 重算 MA20=2.6627、MA60=2.5647 與舊值完全一致，證明價格序列沒有漂移，差異來自舊腳本的事件定義或參數。
因此本 repo 已改用上表的可複現計數作為錨點，不再保留無法複現的數字。
